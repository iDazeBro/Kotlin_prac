Question 1 — The three phases of a frame (THEORETICAL)(a) 3 ta bosqich ketma-ketligi: 1. Composition (qanday UI ko'rsatishni belgilaydi), 2. Layout (qayerda joylashishini o'lchaydi va joylashtiradi), 3. Drawing (ekranda qanday chizilishini hal qiladi).   (b) Layout bosqichining 2 ta qadami: Measure (o'lchash) va Place (joylashtirish).   (c) Nima uchun qoida buziladi: LazyColumn ekranga qancha element sig'ishini bilishi uchun, birinchi navbatda o'zining o'lchamini (Layout bosqichi) bilishi kerak. Shundan keyingina u faqat ekranga sig'adigan bolalarnigina yaratishni (Composition) boshlaydi.   (d) Compose tez ishlashining sababi: U o'zgarmagan qismlarni qayta ishlamay tashlab ketadi (skipping). Bu mexanizm Restart scopes deb ataladi.   
Question 2 — Walk the layout algorithm (THEORETICAL)(a) O'lchash va joylashtirish tartibi: Image o'lchanadi, Text A o'lchanadi, Text B o'lchanadi, Column o'lchanadi. Keyin joylashtirish boshlanadi: Image joylashtiriladi, Text A joylashtiriladi, Text B joylashtiriladi, Column joylashtiriladi.   (b) Column o'lchami: 100x40 (Kengligi max(100, 80) = 100, Balandligi 20+20 = 40). Row o'lchami: 148x48 (Kengligi 48+100 = 148, Balandligi max(48, 40) = 48). Row'ning yuqori-chap burchagiga nisbatan koordinatalari (x, y): Image (0, 0), Column (48, 0), Text A (48, 0), Text B (48, 20). (c) Har bir element faqat bir marta ziyorat qilinadi (single pass). Ma'ruzada bu alohida ta'kidlangan, chunki agar har bir element ikki martadan o'lchansa, daraxt kattalashgani sari ishlash vaqti eksponensial ravishda o'sib ketadi (dastur qotib qoladi).   (d) Bu daraxtni Composition bosqichi yaratgan. Undagi har bir tugun (node) ko'rsatiladigan UI elementini va uning modifierlarini holatini o'z ichiga oladi.
Question 3 — State reads and restart scopes (THEORETICAL)(a) Ha, 1 va 2-kod parchalari bir xil ishlaydi. Har ikkisida ham holat (state) yaratilganda emas, balki ishlatilayotgan paytda (modifier zanjiri qurilayotganda) o'qiladi.   (b) Text("A") uchun offsetX Layout bosqichida (offset lambda ichida) o'qiladi. Text("B") uchun esa Composition bosqichida o'qiladi. offsetX o'zgarganda Text("A") faqat Layout va Drawing bosqichlaridan qayta o'tadi, Text("B") esa Composition, Layout va Drawing bosqichlarining barchasidan qayta o'tadi.   (c) Restart scope – bu holat (state) o'qilganda, qiymat o'zgarsa o'zini qayta ishga tushira oladigan kod blokidir. Composable funksiya tanasida to'g'ridan-to'g'ri qilingan o'qish uchun restart scope – o'sha composable funksiyaning o'zi hisoblanadi.   
Question 8 — Which phase re-runs? (THEORETICAL)(a) Composition bosqichida o'qiladi. O'zgarganda: Composition (ishlaydi), Layout (ishlaydi), Drawing (ishlaydi).   (b) Layout bosqichida (Placement) o'qiladi. O'zgarganda: Composition (skipped - o'tkazib yuboriladi), Layout (ishlaydi), Drawing (ishlaydi).   (c) Composition bosqichida o'qiladi. O'zgarganda: Composition (ishlaydi), Layout (ishlaydi), Drawing (ishlaydi).   (d) Drawing bosqichida o'qiladi. O'zgarganda: Composition (skipped), Layout (skipped), Drawing (ishlaydi).   (e) Layout bosqichida (Measure) o'qiladi. O'zgarganda: Composition (skipped), Layout (ishlaydi), Drawing (ishlaydi).   (f) Drawing bosqichida o'qiladi. O'zgarganda: Composition (skipped), Layout (skipped), Drawing (ishlaydi).   Qaysi birini tanlash kerak: Animatsiyalar uchun iloji boricha (b), (d) yoki (f) ni ishlatgan ma'qul. Sababi, ular Composition bosqichini o'tkazib yuboradi (skip qiladi) va har bir kadrda butun UIni qayta qurmasdan dasturning tez ishlashini ta'minlaydi.
